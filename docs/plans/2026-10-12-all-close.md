# 전체 자료 종료의 독립 선택과 부분 결과
- 목표: Remote의 별도 전체 종료 확인에서 열린 자료별 saved/without-backup/unchanged를 선택하고 저장 실패한 자료는 유지한다. PRD v5 §6.3/14/28, FR-015/020.
- 완료 기준: 정확한 열린 자료 scope/revision/중복/역할 검증, saved worker 검증, 성공 대상만 한 strict CAS로 닫음, 실패한 현재 자료는 계속 발표·다른 자료 자동 노출 금지, 부분 결과/재확인 및 실제 Whale 시험.
- 하지 않는 것: 원본/델타 삭제, Editor 창 닫기, 영구 정리, PDF 복사본/미디어/후속 포맷 전체 완료 판정.

## 영향 범위
- core 내부 CLOSE_DOCUMENTS는 승인 ID만 closed로 만들고 현재가 포함되면 검정 대기, 모든 열린 자료가 끝나면 session timer도 pause한다.
- CLOSE_ALL_DOCUMENTS 외부 요청은 Remote만, choices<=16/중복없음/정확한 열린 scope. saved에 사용하는 .wcp.json은 현재 수업 전체 확정 snapshot이며 한 파일 검증 결과를 saved 선택 자료에만 적용한다.
- 결과는 documentId별 closed/kept/error 및 revision; 부분 성공은 한 transaction, CAS/저장 실패는 아무 대상도 변경하지 않는다. 실패한 현재를 자동 대체하지 않는다.
- UI AllCloseControls dialog, 자료별 select, 수업 전체 파일 저장/선택, 부분 결과/남은 자료 다시 확인. 초안과 임시 복구 데이터는 계속 보존한다.

## 결정
- 비삭제형 종료 정책 유지. 미확정 초안은 수업 전체 파일에 포함되지 않으며 별도 경고한다.
- 한 자료의 저장 실패가 다른 자료의 명시적 백업 없는 종료/변경 없는 종료를 취소하지 않는다. 대신 상태 변경 경쟁/CAS 실패는 batch 전체를 rollback한다.
- user 포괄 진행 승인 적용. 새 권한/패키지/외부 쓰기 없음.
