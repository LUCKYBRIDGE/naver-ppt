# web-ppt 효과 재생 후보 비교
- 목표: 고정 MIT 후보의 실제 클릭 효과 진행을 웨일에서 시험한다.
- 승인: 제품 완성까지 개발 및 포괄 승인. adapter-validation/plan-feature 적용.
- 완료 기준: npm tarball SHA512/실제 LICENSE 확인, 로컬 bundle/CSP/외부 차단, SVG DOM 경계와 제공된 상태/재생 엔진, 교사23쪽 렌더와12단계 진행 증거.
- 하지 않는 것: 기본 Viewer의 innerHTML 사용, 런타임 외부 코드/자료 업로드, 원본 덮어쓰기, 제품 채택/지원 승격.
## 영향 범위
- SVG 검증 경계와 단위 테스트, 별도 격리 실험 스크립트, 검증/라이선스/인수인계 문서.
- 위험: SVG URI/CSS, 엔진 효과 의미 손실, 원본 폰트 차이. 효과 진행은 원본 수준 충실도와 구분한다.
## 단계
1. [x] 고정 후보/라이선스와 SVG 검증 경계, check365tests.
2. [x] 실제 Whale에서23쪽과 효과12단계·외부0·원본 불변 검증. 부모/자식 표시 오류 수정 후 직접 화면 확인. 제품 지원 승격 아님.
