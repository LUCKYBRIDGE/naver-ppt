# PPTX 원본 미디어 타이밍 연결
- 목표: 원본 내장 미디어의 조건·명령과 원본 효과 순서를 함께 해석해, 소유 Player가 검증한 동작만 실행하고 취소/자료교차/복구에도 과거 명령을 자동 재실행하지 않는다. PRD§11/24/25, FR-005/013/014. 사용자 제품 완성 요청 범위.
- 현재: guarded 원본/등록출처/hash 재추출, 수동 미디어 Remote/Player, 효과 requestId/완료pose는 구현됐다. 원본 `p:audio`/`p:video`/`p:cmd` 의미를 기존 shape 애니메이션 모델이 모두 보존한다고 가정하면 안 된다. 교사 원본에는 모델 내장 미디어0이라 합성 근거가 필요하다.

## 근거와 해석 경계
- [Microsoft CommonMediaNode](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.presentation.commonmedianode?view=openxml-3.0.1): 미디어 타이밍은 cTn/대상 및 음소거·음량·정지 시 표시·여러 쪽 재생 속성을 함께 가진다. 원본속성 미발견을 기본 지원으로 치환하지 않는다.
- [Microsoft cmd 구현 설명](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/b2f15f11-5b40-4f67-ae95-5a510c3bea06): 미디어 호출은 원본 타이밍의 대상과 연결된 audio/video 노드 확인이 필요하다. embedded object verb/event와 문자열을 임의 실행 코드로 취급하지 않는다.
- 우선 source XML의 노드/대상·조건을 검사해 Preflight가 원본 트리거 존재와 미지원 의미를 알려야 한다. 이후 명시적 검증 subset의 실행을 연결하고 나머지 요구사항은 열린 상태로 유지한다.
