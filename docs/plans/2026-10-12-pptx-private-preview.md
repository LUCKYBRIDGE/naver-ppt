# PPTX 비공개 미리보기
- 목표: 교사가 PPTX를 원본 그대로 로컬에서 읽고 발표를 바꾸지 않으며 쪽을 탐색한다.
- 완료 기준: 실제 제품 Editor·웨일에서 제공23쪽을 탐색하고 이미지가 표시된다. 선택/원본/발표 Canvas는 유지되고 파일 변경·취소·종료 때 자원을 해제한다.
- 하지 않는 것: 미검증 고급효과/미디어 재생, supported 승격, 원본 저장/전송.
- 승인: 제품 완성까지 개발 및 로컬 작업 승인에 포함.

## 영향 범위
- 기존 모델 Worker의 명시적 preview 응답과 공통 작업 수명, 소유 자산 hydration.
- 새 preview loader/Editor 컴포넌트·안전 SVG·반응형 화면.
- 단위 테스트와 기존 실제웨일 inspection verifier 확장.
- 위험: 비신뢰 SVG/링크·Blob 자원 누수·오래된 완료·학생 화면 혼입.
