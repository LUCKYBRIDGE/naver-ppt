# Player 재생과 자동 넘김
- 목표: Player가 자동 넘김·미디어·타이머 실행 주체가 되며 Remote 닫힘/다른 앱 포커스/Editor 탐색과 무관하게 재생한다. PRD v5 §11/Stage B, FR-004/005/006.
- 완료 기준: 슬라이드>자료>세션 규칙, 경과시간/deadline, 반복/자료 전환 checkpoint와 수동재개 기본값, Player 역할의 좁은advance gate, strict복구·실제Whale5분focus 및 미디어 실파일 검증.
- 하지 않는 것: 서비스워커 장기타이머, 미검증 포맷 미디어 지원 주장, 원본/미디어 자동복제, 늦은 예약으로 다른 자료 변경.
## 영향 범위
- 영상 fixture는 실제 Whale Canvas captureStream/MediaRecorder로 생성한다. 컨테이너 metadata/네이티브 seek/프레임 픽셀을 독립 실험한 뒤만 제품 video 입력·재생 검증에 사용한다. 인코더 추가 설치/원본·미디어 업로드는 없다.
- 로컬 미디어: media/input.ts 네이티브 HTMLMediaElement metadata·헤더/128MB/15초·SHA256 검증, 별도 SourceVault validator/channel와 같은 native handle 저장 경계, 자료별 optional localMedia metadata/epoch bookmark, Editor 등록·재연결, Remote 재생·정지, Player 객체 URL/재생 실패·의미 있는 위치 checkpoint. 파일 bytes는 백업/세션에 넣지 않는다.
- media/autoplay.ts 순수 규칙/시간·다음 대상 계산, document optional autoplayCheckpoint와 DB/백업 검증·복구.
- core/session.ts 다른 자료 전환/페이지 이동/종료에 이전 미디어·checkpoint·문서timer pause. 같은 자료 활성화/Editor 선택은 정지 조건이 아니다. session timer는 별도다.
- 후속 Remote 재생/규칙/타이머 UI와 Player deadline 실행, 역할·epoch·revision 검증 후 자동advance. HTMLMediaElement는 브라우저 재생 엔진을 사용한다.
