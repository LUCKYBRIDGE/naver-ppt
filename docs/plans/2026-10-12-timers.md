# 수업·자료 타이머 실행
- 목표: Remote에서 범위/카운트다운·초시계/공개 표시·시작·정지·초기화를 설정하고 단일 Player가 실제 시간으로 표시·완료 처리한다. FR-016/004/006, PRD v5 §11·Stage B, v4 §8의 충돌 없는 상세 요구.
- 승인: 제품 완성 개발 및 포괄 승인. 기존 presenter-state/plan-feature 적용.
- 완료 기준: 수업 타이머는 A/B 이동에도 진행, 각 자료 타이머는 전환 때 정지·복귀 보존, Player-only 완료·epoch/revision/실제 시간 gate, 백업 경과시간 보존/정지 복원, native Whale Remote닫힘·완료·좁은 화면.
- 하지 않는 것: worker 장기 타이머·매프레임 저장, 자료 원본 변경. 소리 알림/위치 조절은 후속 단계이며 전체 FR-016 완료로 판정하지 않는다.
## 영향 범위
- 기존 globalTimer(session/document)을 읽는 호환 경로 유지. 새로운 자료별 timer optional 필드로 A/B의 서로 다른 타이머를 보존한다. legacy document globalTimer는 명시 설정·조작 때만 자료 timer로 옮긴다.
- TimerState optional mode/visible/epoch, media/timer.ts 실제 elapsed/pause와 저장 validator·bundle복구. 새 설정은 countdown1..86400초/stopwatch0초, 공개표시 Boolean.
- Remote SET/PLAY/PAUSE/RESET_TIMER, 단일 Player FINISH_TIMER: session→documentId/slideId=null, document→현재 발표 documentId/slideId=null. epoch·deadline 재검증·strict 저장.
- Remote 표시/아이콘·Player 공개 projection/표시·deadline. 개인정보/노트/파일명 없음.
