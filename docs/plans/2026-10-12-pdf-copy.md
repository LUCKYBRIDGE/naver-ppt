# PDF 수정본 내보내기
- 목표: 원본 PDF 페이지를 보존하고 확정된 오버레이만 합쳐 새 로컬 PDF를 저장한다. PRD v5 Stage B/§14, FR-013/014.
- 완료 기준: 원본 hash 불변, 페이지 수·crop·회전·원본 벡터 유지, 공개 오버레이만 포함, 실패/취소 시 델타 유지, 실제 출력 readback와 외부뷰어/Whale 검증.
- 하지 않는 것: 원본 덮어쓰기, 노트/수업 기록 포함, 미확정 초안 포함, PDF에 미디어/타이머 저장, 모든 PDF 호환성 확정.

## 영향 범위
- pdf-lib 1.17.1 MIT를 로컬 writer 후보로 실험한다. 기존 PDF.js는 검증/표시용이며 writer가 아니므로 대체하지 않는다. 원본 전체 raster 대안은 벡터/검색 품질을 잃어 기본 경로로 채택하지 않는다.
- src/export/pdfCopy.ts는 원본 bytes/fingerprint/자료 구조를 대조하고 원본 페이지에 PNG 공개 레이어만 추가한다. DOM/font 렌더는 기존 paintOverlays 경계로 분리한다. PDF.js viewport matrix의 역변환으로 crop/회전/UserUnit 좌표를 처리한다.
- src/export/localFile.ts는 기존 .wcp.json 저장 계약을 유지하며 후속 단계에서 PDF 출력용 검증 경로를 공유한다. PDF 성공은 편집정보 종료 증거로 사용하지 않는다.
- 위험: 암호/손상/고급 양식/원본 action/대용량 PDF. 암호 우회 금지, 제한 초과 시 중단, 원본 active content를 안전한 파일로 정화했다고 주장하지 않는다. 오버레이는 raster이며 검색 가능한 텍스트가 아니다.
