# PPTX 충실도 판단과 미지원 효과 사전 안내
- 목표: Stage D 근거를 먼저 정리하고, 유효하지만 미지원인 회전·확대 효과가 발표 화면 초기화를 막는 조건을 발표 전에 알린다.
- 승인: 현재 사용자의 제품 완성 지속 개발 요청에 포함된 방향 점검 해결 작업이다.
- 완료 기준: 합성 유효 OOXML로 실제 Whale 실패 재현, 기존 guard를 그대로 사용한 등록 전 경고, 기존 PDF 발표/원본/세션 보존 검증.
- 범위: 회전·확대 binding의 사전 검사. 자동 정적 fallback은 숨겨진 정답을 노출할 수 있어 제공하지 않는다. 전체 효과/원본 충실도 지원 판정은 별도다.

## 영향 범위
- adapters/pptx: guarded 패키지와 공식 모델에서 회전·확대 binding을 실행하되 재생·세션 명령은 보내지 않는다.
- import: 해당 효과가 있는 자료만 정밀 검사를 실행하고 실패 쪽·안전한 대안을 등록 점검에 표시한다.
- tests/scripts: 합성 autoRev 회전, 정상 회전/확대, 취소/파서 오류, 기존 발표 보존.
- 위험: PPTX 등록 시 해당 효과가 있는 파일에 모델 파싱 비용이 추가된다. 자산은 검사 직후 해제하며 원본을 자동 저장하지 않는다.
