# 실제 교사 PPTX 첫 사례
- 목표: 사용자가 제공한 PPTX를 수정/업로드 없이 두 후보의 실제 웨일 렌더로 평가한다.
- 승인: 사용자 파일 제공 및 기존 전체개발 승인. adapter-validation/presentations 적용.
- 완료 기준: 원본 hash 불변, 23쪽 전체 실행/이미지 decode/오류·외부요청 기록, 일부 화면 직접 확인, 미검증 원본충실도 구분.
