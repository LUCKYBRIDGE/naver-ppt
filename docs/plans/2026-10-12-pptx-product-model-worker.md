# PPTX 제품 모델 Worker
- 목표: 실제 Editor에서 원본 구조와 후보 모델의 손실·효과·미디어 개수를 로컬 검사한다.
- 완료 기준: 고정 버전/라이선스가 제품에 포함되고 로컬 Worker가 실제 웨일에서 23쪽을 검사한다. 취소/실패는 정리되며 발표 상태와 원본은 보존한다.
- 하지 않는 것: 미검증 발표 활성화, supported 승격, 원본 저장/업로드.
- 승인: 사용자의 제품 완성까지 개발 및 모든 승인 요청에 포함된 로컬 구현.

## 영향 범위
- package.json/lock, Vite Worker 설정, 라이선스/산출물 검증.
- PPTX isolatedModel/modelWorker, fileInspection, Editor 검사 선택.
- 단위 테스트 및 실제 웨일 검사 재현 스크립트.
- 위험: 공식 Worker 초기화의 tree shaking, 비신뢰 모델, 작업 취소, 초기 로딩 비용.

## 열린 질문
- PowerPoint 원본 비교와 추가 실제 9종 이상은 계속 미확인이다.
- 후보 모델 검사는 렌더·소리·미디어 재생이나 모델의 완전성을 증명하지 않는다.
