# PPTX 원본 회전 파라미터 보존
- 목표: PRD v5 §7.2/8.3/22.4/24 Stage D에서 발견한 90도→360도 손실을 원본 파라미터 전달로 해결한다. FR-004 복귀 시험도 유지한다.
- 승인: 사용자의 제품 완성까지 개발 요청과 기존 전체 승인.
- 완료 기준: by/from/to의 부호·단위·범위를 검사하고, 기존 엔진이 만든 WAAPI 키프레임에 전달한다. 합성 90도 회전과 완료 pose 복원을 실제 Whale에서 확인한다. 기존 교사 파일·미디어 회귀와 check가 통과한다.
- 하지 않는 것: 자체 타임라인 엔진, 원본 수정, 검증 없는 PPTX 지원 승격. 확대·색상·복합 트리거는 별도 후속이다.

## 영향 범위
- 새 파일: src/adapters/pptx/rotationBehavior.ts, tests/unit/pptxRotation.test.ts.
- 변경: 격리 web-ppt 검증 스크립트와 합성 효과 fixture, 결과·호환성·인수인계 문서.
- 위험: 원본 효과와 후보 step의 잘못된 대응, 다른 애니메이션 취소, 원본에 없는 반복/완료 상태를 추측하는 것. 대응이 모호하거나 조건이 미검증이면 재생 전에 거부한다.

## 열린 질문
- 반복·자동 역재생·누적·색/확대 등 전체 효과 의미는 후속 비교가 필요하다. 이번에 누락을 조용히 기본값으로 바꾸지 않는다.
- from/to의 비기본 변환 조합은 원본 기준 비교 전 지원하지 않는다. by는 현재 계산된 2D 행렬을 보존하며 상대 회전을 전달한다.
