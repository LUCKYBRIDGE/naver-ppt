- 완료 기준: 신규 세션 생성/중복 생성 방지, 상태+receipt 원자적 저장, revision CAS, 저장 실패 후 상태 보존, 연결 재생성 후 복구 테스트 통과.

## 결정
- 상태와 최근 receipt를 하나의 object-store 레코드로 저장한다. 기존 세션 삭제/초기화 API는 추가하지 않는다.
- 쓰기는 durability strict 요청, 미지원이면 실패로 반환한다. 조용히 낮은 내구성으로 바꾸지 않는다.
- 알려지지 않은 DB/레코드 버전과 손상은 복구 오류로 보존한다. 자동 삭제/재생성 금지.
