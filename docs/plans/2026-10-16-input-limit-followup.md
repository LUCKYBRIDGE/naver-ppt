# PPTX 입력 한도 확대 후속 계획

2026-10-16 사용자 결정: 현재는 입력 한도 안에서만 테스트하고, 한도 확대는 후속 개발로 진행한다.

- 현재 PPTX 입력 한도 128MiB(134,217,728 bytes)는 유지한다. 이번 작업에서 제품 코드·한도·권한을 변경하지 않는다.
- owner PC의 현재 검증 대상은 후보 쌍 10종과 한도 이내 단독 PPTX 2종이다. 한도 초과 자료는 보관만 하며 이번 제품 검증·거부 시험에 사용하지 않는다.
- 다음 개발에서는 FR-003/005/013, PRD v5 §11/16/25에 따라 파일 입력·ZIP 파싱·Worker 전송·개별 미디어·동시 준비·보유 자원 경계를 함께 검토한다.
- 새 한도 수치는 실제 파일의 메모리/시간 측정 후 정한다. 파일 한도만 올려 전체 브라우저 메모리 예산을 충족했다고 해석하지 않는다.
- 취소·시간초과·늦은 결과·저장/복구·원본 해시·현재 학생 화면 보존과 대용량 내장 미디어의 수명을 검증한다. 품질 저하나 현재 발표 자원의 강제 해제로 우회하지 않는다.
- 확대 구현 시 새 한도 전후의 단위 테스트와 실제 Whale 제품 시험을 수행하고 성능 예산·지원 매트릭스·실행 결과를 갱신한다.

현재 자료의 상세 경로·해시와 활성/제외 목록은 Git 제외 `test-materials/manifest.local.json`에만 보관한다. 준비된 자료 수는 제품 지원 인수 결과가 아니다.
