# 웨일 세션 메시지와 화면 연결
- 목표: 웨일 확장에서 수업 세션 생성/복구, 공개/비공개 상태 분리, 독립 창 재사용과 동기화를 연결한다.
- 완료 기준: 발신 페이지 역할별 명령 제한, Player 노트 비노출, durable commit 이후 상태 전달, 세션 생성/조회 UI와 재연결, 창 중복 생성 방지 테스트 통과.
- 관련: PRD v5 Stage A, §6/14/17/20/22, FR-001/007/008/014/015.
- 승인: 개발 이어가기 요청에 따라 진행.
- 범위 밖: PDF import/렌더, 미디어, 원본 export, 전체 종료. 등록 자료 없는 세션에 가짜 슬라이드를 표시하지 않는다.

## 영향과 단계
1. [x] 지침/계약/창 코드 확인.
2. [x] 런타임 메시지 검증, 역할별 공개 projection, 최근 세션 조회.
3. [x] 서비스 워커 요청/port 구독과 창 재사용 연결.
4. [x] Launcher 세션 생성/복구, Remote/Editor/Player 상태 연결.
5. [x] 자동 회귀와 화면 크기/오류 확인. 실제 Whale은 실행 파일을 찾지 못해 미실시로 기록.
6. [x] 기록과 다음 PDF 작업 인수인계.

## 경계
- 발신 역할은 sender.url을 runtime.getURL의 확장 페이지와 비교해 판정한다. 요청 본문의 role은 신뢰하지 않는다.
- Player로 전체 ClassSession/노트/editorSelection을 보내지 않는다. 교사 응답도 역할별 대상 명령만 허용한다.
- 원본 바이너리 없는 등록 metadata만 검증한다. 실제 파일 import는 후속 Adapter 경계다.
- Chromium 대역 결과를 Whale 실기기 지원으로 승격하지 않는다.
