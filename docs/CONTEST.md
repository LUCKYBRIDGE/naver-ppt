# 교사 대상 네이버 웨일 공모전 개발 기준

## 확인된 목적

사용자가 2026-10-11 교사 대상 네이버 웨일 공모전 참가를 개발 목적으로 지정했다. 대상 사용자는 수업 자료를 운영하는 교사이며, 학생 출력 화면의 안전과 수업 연속성이 핵심이다. 제품 요구는 [PRD v5](../naver-ppt_PRD_v5.md)를 따른다.

공식 공모전명·응모 자격·마감일·심사 항목·제출 형식·AI 활용 규정은 아직 확인되지 않았다. 2026-10-11 공식 도메인 검색에서 해당 공고를 특정하지 못했다. 공고 확보 후 URL/확인일/조건을 추가한다. 아래 시연 기준은 개발 목표이며 공식 심사 기준이 아니다.

## 시연 목표와 증거

| 장면 | 교실 가치 | 기록할 증거 |
|---|---|---|
| PDF A5→B2→A5 | 자료를 바꿔도 이어서 수업 | 실제 Whale 화면, 샘플/hash |
| A5 발표 중 B8 편집/노트 | 학생 화면을 유지하며 준비 | Player/Editor 동시 화면, 비공개 정보 비노출 |
| 네트워크 차단 후 전환/편집 | 연결이 불안정해도 계속 발표 | 오프라인 조건·버전·시험 결과 |
| 원본 불변 + 새 파일 저장 | 원본과 편집 결과 보존 | 전후 hash, 저장 완료/취소/실패 |
| 재시작 복구 및 현재 종료 | 중단 대비와 다음 자료 노출 방지 | 복구 delta, 검정 대기/나머지 자료 유지 |

학생 정보가 없는 합성 자료로 공개 시연한다. 미검증 PPTX/SHOW/웹 기능은 지원으로 홍보하지 않는다. 실제 수업에서 재현 가능한 동작을 우선한다.

## 공식 기술 근거

- [웨일 매니페스트](https://developers.whale.naver.com/api/extensions/manifest/): MV3 확장 구조.
- [웨일 MV3 전환](https://developers.whale.naver.com/tutorials/mv3-migration/): 서비스 워커와 패키지 제약.
- [웨일 확장 구조](https://developers.whale.naver.com/getting_started/anatomy_1/): extension URL은 runtime.getURL 사용.

확인일: 2026-10-11. API 문서는 실기기 동작/공모전 공고의 증거를 대신하지 않는다.
