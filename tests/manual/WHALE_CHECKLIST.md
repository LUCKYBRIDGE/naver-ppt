# 웨일 실기기 확인표

현재 전 항목 미실시. 테스트 결과에 OS/웨일 버전/디스플레이·DPI/샘플/실행일을 기록한다.

- [ ] `npm run build` 후 dist를 압축해제 확장앱으로 로드.
- [ ] 툴바 런처 표시와 Player/Remote/Editor 각 창 생성. 오류 로그 확인.
- [ ] 다른 앱 클릭 후 독립 Remote가 닫히지 않는지 확인.
- [ ] Remote를 닫아도 Player가 남는지 확인(현재 초기 창 생존만; 재생 검증 아님).
- [ ] Player 생성이 교사 앱 포커스를 강제 회수하지 않는지 확인.
- [ ] 새 수업 생성 → 최근 수업 선택 → 세 창 열기. 팝업 종료/재실행 뒤 수업 목록 복구.
- [ ] 같은 수업/역할 창을 다시 열어 중복 생성이 없는지, 다른 수업은 독립적인지 확인.
- [ ] runtime.getContexts가 자체 화면을 조회하고 새 권한 없이 창 재사용하는지 확인.
- [ ] 서비스 워커 종료 뒤 살아 있는 교사/Player 창 재연결과 DB snapshot 복구. Remote 닫힘은 Player를 종료하지 않음.
- [ ] 등록된 테스트 자료의 비공개 노트 저장/재접속 복구. Player 응답에 제목/파일명/노트/editorSelection/classLog가 없음. 실제 가져오기 전에는 합성 metadata 주입 시험으로 명시.

아래는 후속 기능 구현 뒤 실행한다.

- [ ] Editor에서 PDF 두 개를 실제 선택/등록하고 등록 중 Player 자동 전환 없음. API fallback 여부와 원본 권한 기록.
- [ ] PDF A5→B2→A5 렌더·B8 독립 미리보기/노트 확인. 두 창의 스크린샷·원본 hash 비교.
- [ ] 원본 핸들 재시작 권한/이동·변경·동일 hash 재연결. 저장소에 원본 바이트/Blob이 자동 복제되지 않음.
- [ ] 확장 CSP하의 worker/CMap/표준 폰트/디코더, cold offline 시작/자료 전환, 큰 파일·128MB/2000페이지 제한.

- [ ] PDF A5→B2→A5, 각 판서·노트·레이어 유지.
- [ ] A5 발표 중 B8 비공개 편집, A5 출력 불변.
- [ ] 현재 페이지 편집 확정 전 비공개, 확정 후 반영.
- [ ] 다른 앱 5분 사용: focus/visibility/currentTime/예상·실제 전환 시점 기록.
- [ ] 숨김/최소화는 별도 케이스로 기록; 포커스 이동과 구분.
- [ ] 단일/듀얼/복제 모드, 디스플레이 연결 해제·DPI 변경 복구.
- [ ] 현재 종료: 나머지 보존·검정 대기. 전체 종료: 별도 확인·dirty 선택.
- [ ] 실제 로컬 다운로드 완료·취소·오류, 원본 해시, 외부 뷰어 열기.
- [ ] 강제 종료·서비스 워커 종료·원본 이동·권한 재요청·편집정보 복원.
- [ ] 오프라인, 큰 문서, 누락 폰트, 키보드/터치/IME.
