# 웨일 실기기 확인표

현재 전 항목 미실시. 테스트 결과에 OS/웨일 버전/디스플레이·DPI/샘플/실행일을 기록한다.

- [ ] `npm run build` 후 dist를 압축해제 확장앱으로 로드.
- [ ] 툴바 런처 표시와 Player/Remote/Editor 각 창 생성. 오류 로그 확인.
- [ ] 다른 앱 클릭 후 독립 Remote가 닫히지 않는지 확인.
- [ ] Remote를 닫아도 Player가 남는지 확인(현재 초기 창 생존만; 재생 검증 아님).
- [ ] Player 생성이 교사 앱 포커스를 강제 회수하지 않는지 확인.

아래는 후속 기능 구현 뒤 실행한다.

- [ ] PDF A5→B2→A5, 각 판서·노트·레이어 유지.
- [ ] A5 발표 중 B8 비공개 편집, A5 출력 불변.
- [ ] 현재 페이지 편집 확정 전 비공개, 확정 후 반영.
- [ ] 다른 앱 5분 사용: focus/visibility/currentTime/예상·실제 전환 시점 기록.
- [ ] 숨김/최소화는 별도 케이스로 기록; 포커스 이동과 구분.
- [ ] 단일/듀얼/복제 모드, 디스플레이 연결 해제·DPI 변경 복구.
- [ ] 현재 종료: 나머지 보존·검정 대기. 전체 종료: 별도 확인·dirty 선택.
- [ ] 실제 로컬 다운로드 완료·취소·오류, 원본 해시, 외부 뷰어 열기.
- [ ] 강제 종료·서비스 워커 종료·원본 이동·권한 재요청·편집정보 복원.
- [ ] 오프라인, 큰 문서, 누락 폰트, 키보드/터치/IME.

각 결과를 `../../docs/TEST_RESULTS.md`에 연결한다. 체크 자체가 지원 수준을 자동 승격하지 않는다.
